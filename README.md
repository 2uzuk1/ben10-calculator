# Ben 10 Calculator

A web calculator with parentheses, built as a learning project using vanilla JavaScript—no frameworks.

## Features

- Basic operations: addition, subtraction, multiplication, and division
- Parentheses with operator precedence
- Percentage and sign toggle
- Keyboard support
- Error handling, including division by zero and invalid expressions

## How to Use

Open `index.html` in your browser. No installation or server required.

## Technologies

- HTML, CSS, and vanilla JavaScript
- A custom recursive parser that evaluates expressions without using `eval()`

## What I Learned

- The difference between using `eval()` and building a custom parser with a tokenizer and recursive parsing
- String and regular expression manipulation
- Managing state without a framework
